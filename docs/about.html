About

993 buildable open-source Eurorack modules from 313 GitHub repositories by 233 makers. The table behind this site is data/modules.tsv in daaaaaaaaaniel/my-awesome-eurorack; the site is regenerated from it and adds nothing.

What the fields mean

Type
The raw type string from the repo, plus tags from data/type-categories.tsv (multi-function modules get several). Tags marked draft are keyword-rule proposals awaiting review.
Maker
As recorded in the repo. A clone or port is credited "Original + Porter" (e.g. "Mutable Instruments + Sluisbrinkie"); the Maker filter lists each name separately, so the module appears under both. Spelling variants of one maker are folded together by data/maker-aliases.tsv; the credit line keeps the repo's spelling.
Mounting
SMD, THT or both, read from the board files' footprints or from a statement in the repo. Blank means neither was available in scope — it is not a guess. "Component confidence" says which: Strong (footprints counted), Stated (repo says so in text), Weak, Deferred (no machine-readable board file or BOM found).
Files in repo
Which design files exist: a schematic (linked when it's a single PDF), KiCad / Eagle / other layout sources, gerbers, a machine-readable BOM.
License
The raw statement is kept as recorded. On top of it, data/license-map.tsv splits each statement into grants — a module can carry one license for hardware and another for firmware — each with a version-free family (filterable by ?lic= in the URL) and a terms class that describes the license family, never the module (the License terms filter). Versions are shown only when the repo states one. A blank cell means no license found in the files checked, which is not the same as the repo saying there is none. Rules in data/licenses.md.
Build status
prototype when the repo clearly labels the build untested or in progress; prototype? when the wording is ambiguous. Never inferred from a version number.
Evidence
Each module page quotes the file path or README line every non-blank cell came from.

Rules the data follows

  • Never invent a value. A blank cell is correct; a plausible guess would be acted on when ordering parts.
  • Every non-blank cell traces to a file path in the repository tree or a quoted line of text.
  • One row per buildable module variant, not per repository.
