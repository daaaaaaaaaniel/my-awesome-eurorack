Module page layouts: current + three alternatives

The same two modules in each layout. Helium (Winterbloom) is a rich page: photos, KiCanvas viewer, PDF schematic, SMT assembly, a three-part licence. Plaits (Mutable Instruments) has no viewer: panel drawing, XLSX BOM, Eagle sources. No data was added or removed in any variant; only arrangement and styling differ. Links to other modules ("all modules", "More by …") don't work in the mockups.
