## Setup

Install toolchain:
```
$ arduino-cli core install arduino:avr
```

Add your unix user to the `dialout` group for non-root access to the serial
port.

## Common Commands

### List Connected Boards

```
$ arduino-cli board list
```

### Compile a Sketch

```
$ make compile
```
