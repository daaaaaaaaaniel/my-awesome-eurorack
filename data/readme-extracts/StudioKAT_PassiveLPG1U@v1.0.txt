# Passive LPG 1U
![Passive LPG 1U_v1.0_Front](<Images/Passive LPG 1U_v1.0_Front.jpg>)

## 概要 / Overview

**Passive LPG 1U** は、Intellijel 1U 規格に準拠したパッシブ・ローパスゲートです。  
スイッチの位置により、以下の3つのモードから音色を選択できます。  
左：Low Pass Gate  
中央：Vactrol VCA  
右：Dirty VCA  

**Passive LPG 1U** is a passive low-pass gate module designed for the Intellijel 1U format.  
The switch allows you to select from three different modes:  
Left: Low Pass Gate  
Center: Vactrol VCA  
Right: Dirty VCA  


## 仕様 / Spec
- Format: Eurorack (Intellijel 1U)
- Function: Low Pass Gate
- Current needs: +12V: 0mA, -12V: 0mA
- Width: 6 HP
- Depth: 20mm
